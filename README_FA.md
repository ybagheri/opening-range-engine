# موتور رنج بازگشایی — استراتژی NY Opening Range Pullback (US30)

**یک سیستم تحقیقاتی قابل بازتولید برای MetaTrader 5. این یک پروژه تحقیقاتی
است، نه توصیه معاملاتی. هیچ سودآوری‌ای ادعا یا القا نمی‌شود.**

## این پروژه چیست

این مخزن، استراتژی **شکست رنج بازگشایی نیویورک + بازگشت + تأیید اکشن قیمت**
(مشخصات استراتژی نسخه ۱.۰) را برای بازگشایی سش نقدی نیویورک روی US30
(داج جونز CFD) پیاده‌سازی، تست و اعتبارسنجی می‌کند؛ با معماری‌ای که بعداً
از NAS100، XAUUSD، GER40، EURUSD و نمادهای دیگر MT5 پشتیبانی می‌کند.

خط لوله کاملاً ترتیبی است و هیچ مرحله‌ای به این دلیل که نتیجه قبلی سودآور
به نظر می‌رسد، رد نمی‌شود:

```text
فرضیه استراتژی → مشخصات رسمی → اندیکاتور MT5 → شناسایی سیگنال تاریخی →
مجموعه‌داده معاملات → بک‌تست → تحلیل آماری → تحقیق پارامترها → تست خارج نمونه →
اعتبارسنجی Walk-Forward → تحلیل مونت‌کارلو → تست دمو آنلاین → ارزیابی استحکام →
EA اختیاری
```

## ساختار مخزن

| مسیر | هدف |
| --- | --- |
| `MQL5/Indicators/NY_OR_Pullback_v1.mq5` | اندیکاتور MT5 نسخه ۱.۰ (نمایش نموداری، ماشین حالت بلادرنگ، بدون اجرای معامله) |
| `engine/` | موتور تحقیقاتی پایتون: منطقه زمانی نیویورک، سش، بایاس، سیگنال‌ها، بک‌تستر، معیارها، کیفیت داده |
| `tests/` | تست‌های واحد، یکپارچگی، قطعیت، DST، مرزی، داده گمشده و بدون look-ahead |
| `docs/` | مشخصات استراتژی، رجیستری پارامترها، معماری |
| `data/` | داده میله‌ای ورودی (CSV) — کامیت نمی‌شود |
| `results/` | گزارش‌ها و CSVهای تولیدشده — کامیت نمی‌شود |
| `HANDOFF.md` | **نقطه ادامه‌دهی معتبر** — اول این را بخوانید |

## هشدار ریسک
